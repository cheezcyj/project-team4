# 참고 데이터 점검

점검일: 2026-10-20. `data/csv.zip` 내부 파일을 직접 읽었으며 원본은 수정하지 않았습니다. 출처 기관·입수 경로는 같은 날 사용자가 전달한 정보를 반영했습니다. 아래 제약은 추출 CSV 기준이며, 추가로 받은 SAS 원본의 변수와 읽는 방법은 [SAS 안내](SAS_GUIDE.md)를 참고하세요. SAS 원본에는 표본 설계·가중치와 `NF_INTK` 등 CSV에 없는 변수가 있습니다.

공공데이터포털은 입수 경로이며 제공기관과 구분합니다. 식품영양성분 CSV의 `제공기관명`은 50,000행 모두 `식품의약품안전처`로 확인했습니다. 위 기관·경로 표시는 사용자 전달 정보이고, 원본 게시물·다운로드 URL과 추출 과정을 독립적으로 확인한 것은 아닙니다.

- 건강검진과 섭취 기록은 `ID`로 연결됩니다. 섭취 ID 6,802개가 모두 건강검진에 존재하며, 검진에만 있는 ID는 195개입니다.
- 섭취 행은 완성된 한 끼 또는 한 가지 메뉴와 동일하다고 단정할 수 없습니다. 소금 등 식재료 수준의 기록이 포함됩니다.
- 섭취 기록의 `N_FCODE`는 문자열로 보존해야 합니다. 앞에 0을 채워 5자리로 만들면 고유 코드 2,301개가 코드북 식품코드와 모두 연결됩니다.
- 섭취 기록의 `N_FCODE`와 별도 영양성분 CSV의 `식품코드`가 정확히 일치하는 코드는 **0개**입니다. 코드북 연결이 영양성분 CSV까지의 연결을 의미하지 않습니다.
- 이름만으로 두 식품 데이터를 합치면 동명이품·가공 상태·단위 차이가 생길 수 있으므로, 검증된 매핑 없이는 별도로 사용합니다.

| 항목 | 점검 결과 | 구현·분석 시 처리 |

| 영양 DB의 탄수화물 | 11,158행 결측, 22.32% | 해당 성분은 정보 없음으로 표시. 합계도 불완전함을 표시 |
| 영양 DB의 식이섬유 | 44,793행 결측, 89.59% | 초기 추천·정렬의 필수 조건으로 사용하기 어려움 |
| 영양성분 기준량 | 100g: 40,653행, 100ml: 9,347행 | 입력량과 같은 단위로 환산. 밀도 없이 g과 ml를 상호 변환하지 않음 |

| 검진 혈당·당화혈색소 | `HE_GLU` 702행, `HE_HBA1C` 700행 결측 | 0으로 대체하지 않음 |
| `HE_DM_HB` | 1: 2,813명, 2: 1,844명, 3: 959명, 결측: 1,381명 | 검진 변수설명서가 없으므로 코드 의미·정의부터 확인 |
| 검진 연령 | 관측값 1~80 | 성인 대상 분석이면 대상 연령을 먼저 정의하고 분모를 다시 계산 |

개인별 섭취 행의 `NF_CHO`, `NF_SUGAR`, `NF_EN`, `NF_PROT`, `NF_FAT`를 그대로 합산하면 각각 검진 파일의 `N_CHO`, `N_SUGAR`, `N_EN`, `N_PROT`, `N_FAT`와 연결 가능한 **6,802명 전원에서 절대 차이 0.01 이내**로 일치합니다. 이 결과는 중복 행을 삭제하지 않은 원본 기준입니다. 따라서 제공된 `NF_*` 값을 일괄적으로 100g당 성분으로 취급해 다시 섭취량을 곱하면 안 됩니다. 공식 변수 정의는 별도로 확보해야 합니다.

## 가능한 활용과 아직 필요한 자료

현재 개발기획서 개정 1.2의 필수 범위는 인증·동의와 수동 혈당 기록·조회·수정·삭제 및 최근 7일 그래프입니다. 시연에는 가상 데이터를 사용하며, 위 공공데이터를 앱 운영 DB에 적재할 필요는 없습니다. 기존 데이터는 주제 조사와 후속 식사·영양 기능의 참고자료로 둡니다. 조사 대상자 ID를 서비스 회원으로 간주하지 않습니다.

후속 기능을 확장한다면 음식 검색과 영양성분 비교, 원본 표본의 섭취·검진 지표 탐색을 시작할 수 있습니다. 실제 서비스의 사용자 기록은 조사 원자료와 구분하여 저장해야 합니다.

- 시간축: 검진 파일에는 연도만 있고 섭취 파일에는 `N_MEAL_T`가 있습니다. 식사 날짜와 반복 혈당 측정값이 없어 개인별 식후 혈당 변화나 미래 혈당을 검증할 수 없습니다. `N_MEAL_T`의 시간 형식·특수 코드는 변수설명서 확인이 필요합니다.
- 예측 모델: `HE_DM_HB`를 목표값으로 사용하려면 정의를 먼저 확인해야 합니다. 정의에 혈당·당화혈색소가 쓰였다면 이를 입력에 포함하는 분류는 목표값을 재현하는 누수가 될 수 있습니다. 식품 행을 임의 분할하면 같은 사람의 기록이 학습·평가에 섞입니다.
- 대표성: 제공 CSV에는 표본가중치·층화·집락 변수가 없습니다. 관측 표본의 비율을 도시 또는 전체 국민의 유병률로 제시하지 않습니다.
- 지역 연결: 도시·거주지·시설 좌표가 없어 지역별 분석이나 가까운 보건소 안내에는 추가 데이터가 필요합니다.
- 출처: 사용자는 건강검진·식품섭취·코드북의 출처를 질병관리청, 영양성분의 입수 경로를 공공데이터포털로 전달했습니다. 칼럼명과 코드북은 국민건강영양조사 형식과 부합하고, 영양 CSV의 제공기관명은 전부 식품의약품안전처입니다. 원본 상세 URL, 원자료 버전, 추출 기준, 이용 조건은 아직 확인하지 못했습니다.
