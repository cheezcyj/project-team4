# 건강 뉴스 연결과 이용조건

건강 뉴스는 [보건복지부 공식 RSS](https://www.mohw.go.kr/rss/board.es?mid=a10503000000&bid=0027&info)의 보도자료 중 건강 관련 소식을 사용합니다. 별도 API 키는 필요하지 않습니다.

## 표시하는 내용

- 제목, 최대 180자의 짧은 발췌, 게시일과 작성부서(제공된 경우)
- 제공기관, 원문 링크, 공공누리 제1유형 이용조건 링크
- 기사별 이용허락 영역에서 제1유형 표시와 출처표시 조건을 확인한 경우에만 게시

사진·로고·영상·첨부파일·기사 전문·외부 언론사 기사는 가져와 게시하지 않습니다. 다른 공공누리 유형, 제3자 권리나 별도 이용 제한, 확인할 수 없는 이용조건은 자동 승인하지 않습니다.

## 출처와 조건

- [공공누리 제1유형 및 조건](https://www.mohw.go.kr/menu.es?mid=a10103020100)
- [보건복지부 저작권 정책](https://www.mohw.go.kr/menu.es?mid=a10103010400)
- 확인일: 2026-10-24

제1유형은 출처표시 조건으로 상업·비상업 이용과 변경을 허용합니다. 앱은 기관·작성자(제공된 경우)·게시일·원문·이용조건을 표시하고, 본문 일부를 발췌했다는 사실을 안내합니다. 이 조건이 모든 사진·첨부파일이나 제3자 자료의 권리까지 허락한다는 의미는 아닙니다. 각 기사의 허락 상태를 조회 때 확인합니다.

## 조회와 개인정보

외부 요청은 고정된 보건복지부 HTTPS 주소만 허용하며, 사용자 쿠키·인증 헤더·질문·프로필·개인 건강기록을 전달하지 않습니다. 검색어는 현재 브라우저에 불러온 뉴스 안에서만 사용합니다.

서버는 결과를 15분간 공유하고 중복 조회를 합칩니다. 실패 후에는 1분간 재시도를 제한하며, 최근 6시간 안에 확인한 목록이 있으면 갱신 실패 안내와 함께 유지합니다. 기사별 이용조건 확인에 실패한 항목은 새 목록에서 제외합니다. 인터넷 연결과 제공처의 응답에 따라 실제 표시되는 기사 수는 달라집니다.

이 포트에는 뉴스 원문 사본, 개인 문서, 운영 환경파일이나 키를 포함하지 않습니다. 자동 검사에서는 가상 기사로 정상·빈 목록·실패·재시도·접근성을 확인하고, 실제 외부 연결 확인은 별도로 수행합니다.
