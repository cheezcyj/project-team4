# 당뇨병 관리 서비스 문헌 정리

확인일: **2026-10-21** · 대상 프로젝트: 수동 혈당 기록·조회·그래프를 제공하는 당뇨관리 웹앱.

공식 지침·교육자료 2건과 연구논문 6편을 선별했다. 임상적 배경, 입력·조회 사용성, 기록 지속성에 초점을 맞춘 프로젝트용 검토이며 전체 관련 문헌을 망라하는 체계적 문헌고찰은 아니다. 논문의 결과와 이 프로젝트에 대한 설계 제안을 구분한다. 앱 구현·사용성·혈당 개선 효과를 검증한 문서는 아니다.

## 공식 지침·교육자료

### G01. 대한당뇨병학회 2025 진료지침

**Kang S et al.** *2025 Clinical Practice Guidelines for Diabetes Management in Korea: Recommendation of the Korean Diabetes Association.* Diabetes & Metabolism Journal. 2025;49(4):582–783.

[학회 안내](https://diabetes.or.kr/bbs/?code=guide&mode=view&number=2078&page=1) · [DOI: 10.4093/dmj.2025.0469](https://doi.org/10.4093/dmj.2025.0469) · [PMC 원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC12270580/)

- **확인 범위:** 혈당 모니터링과 당뇨병 자기관리교육 관련 부분. 자가혈당측정·연속혈당측정과 장기 지표인 당화혈색소를 구분하며, 자기관리교육과 환자 상황을 고려한 관리의 중요성을 다룬다.
- **적용 제안:** 측정값·실제 측정시각·측정상황을 함께 보존하고, 수치와 단위를 명확하게 표시한다. 이 필드 구성은 프로젝트의 설계 판단이며 지침이 동일한 앱 입력 양식을 지정한 것은 아니다.
- **해석 범위:** 진료·교육 지침을 특정 앱의 효과 근거로 사용할 수 없다. 대상·치료 상황에 따른 차이가 있어 단일 기준만으로 모든 사용자를 자동 판정하는 기능은 별도 검토가 필요하다.

### G02. 질병관리청 국가건강정보포털 「당뇨병」

**질병관리청.** 등록 2020-08-30, 페이지 표시 최종 업데이트 **2026-09-16**.

[공식 교육자료](https://health.kdca.go.kr/healthinfo/biz/health/gnrlzHealthInfo/gnrlzHealthInfo/gnrlzHealthInfoView.do?cntnts_sn=5305)

- **확인 범위:** ‘자가 관리’의 혈당검사 시기 및 ‘자가혈당측정 및 기록 방법’. 식후 2시간을 식사 시작 시점에 연결해 설명하고, 측정 시점별 의미를 구분한다.
- **적용 제안:** ‘식후 2시간’ 선택지에 짧은 설명을 제공한다. ‘측정시각’과 서버의 ‘저장시각’을 구분하고 사용자가 과거 측정시각을 지정할 수 있게 한다.
- **해석 범위:** 환자 교육자료이며 ‘입력 항목을 줄이면 지속 사용이 증가한다’는 가설의 직접적인 실험 근거는 아니다. 페이지 갱신일과 본문에 인용된 통계의 조사연도를 구분한다.

## 앱 사용성과 기록 지속성 연구

### L01. 당뇨 앱 사용 경험에 대한 체계적 문헌고찰

**Patail K et al.** *What are the perceptions and experiences of adults using mobile applications for self-management in diabetes? A systematic review.* BMJ Open. 2025;15(1):e086671.

[발행처 원문](https://bmjopen.bmj.com/content/15/1/e086671) · [DOI: 10.1136/bmjopen-2024-086671](https://doi.org/10.1136/bmjopen-2024-086671)

- **설계·대상:** 2007~2023년 발표된 성인 당뇨병 관련 **질적 연구 24편**을 종합했다. 당뇨병 유형·국가·연령이 서로 다른 연구가 포함된다.
- **핵심 결과:** 과도한 정보 입력, 기기 호환성, 앱 중단 등 사용상의 어려움이 반복됐다. 약 40%라는 표현의 분모는 **포함된 연구 수**다.
- **한계:** 질적 경험의 종합이며 앱 사용자 전체의 불만율·이탈률이나 특정 화면 개선의 효과 크기를 추정한 결과가 아니다.
- **적용 제안:** 입력 부담·작은 글씨·어려운 탐색·오류 처리를 점검 항목으로 삼는다. 실제 개선 여부는 우리 화면의 과제 수행 결과로 확인한다.
- **확인 위치:** Abstract의 Results, Results의 ‘Effort expectancy’, Discussion.

### L02. 최초 사용자의 입력·저장·보고서 이해 문제

**Fu HNC, Jin D, Adam TJ.** *Content Analysis: First-Time Patient User Challenges with Top-Rated Commercial Diabetes Apps.* Telemedicine and e-Health. **2021**;27(6):663–669. 온라인 선공개 2020-08-13.

[PMC 본문](https://pmc.ncbi.nlm.nih.gov/articles/PMC8349717/) · [PubMed](https://pubmed.ncbi.nlm.nih.gov/32795144/) · [DOI: 10.1089/tmj.2020.0128](https://doi.org/10.1089/tmj.2020.0128)

- **설계·대상:** 성인 **92명**이 두 당뇨 앱을 처음 사용하며 수행한 과제의 관찰기록·발언을 내용분석했다.
- **핵심 결과:** 입력 버튼 탐색, 작은 터치 영역, 기본값 변경, 저장 확인 부족, 보고서·아이콘 이해에서 어려움이 나타났다.
- **한계:** 당시 두 앱의 최초 사용 경험이다. 현재 닥터다이어리의 동작이나 국내 전체 사용자의 장기 사용을 직접 평가하지 않았다.
- **적용 제안:** 저장 완료 표시, 이해하기 쉬운 버튼 이름, 수정 결과 확인, 그래프의 단위·범례를 점검한다. 기본값은 사용자가 확인·변경할 수 있도록 한다.
- **확인 위치·열람 상태:** Methods, Results, Table 3의 PMC 본문 검색 추출과 서지정보 확인. 공개 원문 XML은 확보하지 못했으며 로컬 원문 사본은 없다.

### L03. 국내 연구의 식사·운동·복약 입력률

**Oh SW et al.** *Effect of an Integrative Mobile Health Intervention in Patients With Hypertension and Diabetes: Crossover Study.* JMIR mHealth and uHealth. 2022;10(1):e27192.

[발행처 원문](https://mhealth.jmir.org/2022/1/e27192/) · [DOI: 10.2196/27192](https://doi.org/10.2196/27192)

- **설계·대상:** 국내 대학병원 2곳에서 37명 모집, **32명 분석**. 3개월씩 두 기간으로 구성된 교차연구로, 기기·생활습관 앱·복약 앱 등이 결합된 개입이다.
- **핵심 결과:** 논문이 보고한 입력률은 식사 **24.9%**, 운동 **5.3%**, 복약 **84.0%**다. 개입과 통상관리 간 당화혈색소 변화 등에 유의한 차이는 확인되지 않았다.
- **한계:** 입력률은 이 연구의 항목별 지표이며 ‘앱을 계속 쓰는 사람의 비율’이 아니다. 서로 다른 입력 기능과 개입 요소가 있어 필드 수만으로 차이를 설명할 수 없다.
- **적용 제안:** 항목별 기록 부담을 구분하고, 기록 기능 구현과 임상 개선 효과를 별도로 평가한다.
- **확인 위치:** Methods의 Study Design, Results의 Table 2와 입력률 설명, Discussion.

### L04. 식생활 앱의 장벽과 사용자별 차이

**Montilva-Monsalve J, Dimantas B, Perski O, Gutman LM.** *Barriers and Enablers to the Adoption of a Healthier Diet Using an App: Qualitative Interview Study With Patients With Type 2 Diabetes Mellitus.* JMIR Diabetes. 2023;8:e49097.

[발행처 원문](https://diabetes.jmir.org/2023/1/e49097/) · [DOI: 10.2196/49097](https://doi.org/10.2196/49097)

- **설계·대상:** 최근 진단 집단 **8명**, 장기 진단 집단 **15명**을 대상으로 한 두 질적 인터뷰 연구다. Gro Health 앱 사용 경험을 조사했다. 최근 진단 집단의 모집 기준에는 당뇨병 전단계도 포함됐다.
- **핵심 결과:** 기능 선택·식품량 측정·일부 조리법 실천의 어려움, 앱 활용 기술과 콘텐츠 관심의 차이가 보고됐다.
- **한계:** 특정 식생활 앱과 소규모 집단의 경험이다. 국내 음식 검색의 실패율이나 ‘입력 항목을 줄인 효과’를 수치로 증명하지 않았다.
- **적용 제안:** 식사 기능을 확장한다면 음식 선택·분량·설명·도움말을 함께 검토한다. 혈당 기록 MVP에 모든 식사 정보를 필수 입력으로 추가할 근거로 해석하지 않는다.
- **확인 위치:** Abstract, Methods의 두 연구 대상, Results의 Skills·Behavioral Regulation 관련 설명.

### L05. 기기 연동 앱의 리뷰 602개 분석

**Turner J, Stawarz K.** *Understanding Device Integrations Within Diabetes Apps: Mixed Methods Analysis of App Features and User Reviews.* JMIR Diabetes. 2025;10:e62926.

[발행처 원문](https://diabetes.jmir.org/2025/1/e62926/) · [DOI: 10.2196/62926](https://doi.org/10.2196/62926)

- **설계·대상:** 연동 기능을 다루는 당뇨 앱 **21개**, 관련 리뷰 **602개**를 분석했다. 리뷰는 2023년 10~11월 수집했으며 영어·기능 관련 내용 등 선정 조건이 있다.
- **핵심 결과:** 문제를 언급한 리뷰는 **378개, 62.8%**다. 기기 연동 관련 문제를 언급한 리뷰는 **280개, 46.5%**다.
- **한계:** 선정된 리뷰의 비율이며 전체 사용자 불만율이나 국내 앱의 현황을 대표하지 않는다. 기기 연동 중심의 조사다.
- **적용 제안:** 저장·접근·데이터 확인의 신뢰성을 검증 항목에 반영한다. 기기 연동을 제외한 수동 기록 앱의 우월성을 입증하는 자료로 쓰지 않는다.
- **확인 위치:** Methods의 User Reviews, Results의 Overview·Device Integration Issues.

### L06. 국내 개인화 자기관리 앱의 18개월 사용 경험

**Lee H, Lee D, Kim M.** *Adherence-based experiences with a personalized self-care program for type 2 diabetes in South Korea: a mixed-methods study.* Journal of Korean Biological Nursing Science. 2025;27(4):706–717.

[DOI: 10.7586/jkbns.25.067](https://doi.org/10.7586/jkbns.25.067) · [PMC 원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC13268335/)

- **설계·대상:** 원 연구 개입군 110명 중 18개월 추적을 완료한 사람은 67명이다. 앱 미사용자 15명과 인터뷰 거절 2명을 제외한 **50명**을 분석했다. 주 4회 이상 사용 집단 **33명**, 그 미만 **17명**이다.
- **핵심 결과:** 낮은 사용 집단에서 바쁜 생활과 동기·사용상의 어려움 등이 보고됐다. 높은 사용 집단에서만 일반 식사행동과 당화혈색소의 유의한 집단 내 전후 개선이 관찰됐다.
- **한계:** 사용 빈도에 따라 사후 구분한 집단이며 무작위로 배정한 비교가 아니다. 미사용자 제외와 집단 간 시작점 차이를 고려해야 한다. ‘50명 중 33명’은 최초 참여자의 유지율이 아니다.
- **적용 제안:** 기록을 다시 시작하기 쉬운 흐름과 결과 확인을 검토한다. 단기 시연 결과로 장기 지속성이나 혈당 개선을 주장하지 않는다.
- **확인 위치:** Methods의 Participants, Results, Table 1, Discussion.

## 문헌에서 설계·검증으로 연결하기

아래는 문헌을 참고한 **설계 제안과 검증 계획**이다. 기능 추가를 확정하거나 구현이 끝났다는 뜻이 아니다.

| 검토할 사항 | 참고 | 제안 | 확인할 결과 |
| --- | --- | --- | --- |
| 입력 부담 | L01·L02·L03 | 필수 입력과 선택 메모를 구분하고 동선을 짧게 구성 | 같은 기록 과제의 시간·완료 여부·입력 실수 |
| 측정 맥락 | G01·G02 | 수치·단위·실제 측정시각·측정상황을 명확하게 표시 | 과거 측정값도 의도한 시각·상황으로 저장되는지 |
| 기본값 | L02 | 기본값을 눈에 보이게 제시하고 변경을 쉽게 제공 | 기본값 때문에 잘못 저장된 경우와 수정 성공 여부 |
| 저장·수정의 확실성 | L02·L05 | 완료 표시와 저장된 기록 재확인 경로 제공 | 새로고침·재로그인 후 값 일치, 실패 시 입력 유지 |
| 그래프 이해 | L02 | 단위·날짜·측정점을 표시하고 미측정을 0으로 채우지 않음 | 특정 날짜의 수치 찾기와 빈 날짜 해석 과제 |
| 재방문·지속 사용 | L06 | 최근 기록 확인과 기록 재개를 쉽게 구성 | 단기 과제 성공부터 평가하고 장기 유지율은 별도 관찰 |
| 식사 기능 확장 | L04 | 음식 검색·분량 입력·도움말을 함께 설계 | 대상 사용자의 실제 음식 검색과 분량 입력 과제 |

현재 수동 기록 기능의 운영 데이터는 사용자가 입력한 기록이다. 국민건강영양조사 자료는 집단의 검진·식생활 탐색에 활용할 수 있으나, 앱의 입력 편의성이나 장기 유지 효과를 직접 검증하는 자료는 아니다. 활용 분석을 정할 때는 [데이터 설명서 메모](DATA_DOCUMENTS.md)의 변수 정의와 표본 설계를 먼저 확인한다.

## 다음 확인 항목

- U01의 정확한 서지정보와 원문 확보. ‘634명’의 분석 대상·연구기간·이용 지속 정의를 확인한다.
- 스크린샷의 2023년 식사 앱 문헌 링크를 확보하면 L04와 같은 연구인지 재확인한다.
- 시연 가능한 화면에서 ‘가상 혈당 등록 → 저장 확인 → 날짜별 조회 → 수정’ 과제를 수행하고, 위 표의 결과를 기록한다. 편의 표본의 초기 테스트 결과와 실제 당뇨 환자에 대한 검증을 구분한다.
- 기능 범위를 변경하면 해당 기능에 직접 필요한 근거를 추가한다. 이번 문헌만으로 챗봇·예측·개인별 음식 추천의 성능이나 효과가 검증된 것은 아니다.
