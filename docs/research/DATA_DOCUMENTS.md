[국민건강영양조사 제9기(2022-2024) 원시자료 이용지침서](<../../data/국민건강영양조사+제9기(2022-2024)+원시자료+이용지침서.pdf>)

- 표지 표시: 최초 공개 **2025년 12월**, 최근 업데이트·수정 **2026년 7월**.

## 분석 전에 반영할 변수 정의

| 변수 | 지침서에서 확인한 의미 | 분석 시 주의점 |
| --- | --- | --- |
| `HE_glu` | 공복혈당, mg/dL | 식후 혈당이나 반복 자가측정 기록과 구분 |
| `HE_HbA1c` | 당화혈색소, % | 공복혈당과 다른 지표이며 단위도 다름 |
| `HE_DM_HbA1c` | 1: 정상, 2: 당뇨병 전단계, 3: 당뇨병 | 비임신·공복 등 정의 조건 확인. 혈당·당화혈색소·진단·치료 정보로 구성되므로 해당 항목을 입력으로 분류하면 목표값 재현에 가까워질 수 있음 |
| `N_TD_WT` | **음식**의 섭취량, 중량 g | 식재료별 섭취량을 이 변수로 대체하지 않음 |
| `NF_INTK` | **식품별** 섭취량, g | 식품·재료 기준 섭취량을 분석할 때 확인 |
| `NF_INTK3` | 3차 식품코드의 기준식품으로 환산한 섭취량 | 고형분 기준 환산량이며 `NF_INTK`와 동일하게 취급하지 않음 |
| `N_FCODE` | 5자리 식품코드 | 앞자리 0을 보존하고 해당 연도 코드자료집과 연결 |
| `N_KINDG1` | 식품군 분류 | 식품명 문자열로 임의 분류하기 전에 이 변수의 정의 확인 |

`HE_DM_HbA1c`는 실제 2024 SAS 변수 목록에서도 확인했다. 이전 추출 CSV의 `HE_DM_HB`와는 이름이 다르므로 같은 항목인지 값과 추출 과정을 대조한 뒤 연결해야 한다.

이 지침서의 분류는 조사자료를 분석하기 위한 정의다. 서비스 사용자가 입력한 한 번의 혈당으로 진단을 확정하는 규칙으로 사용하지 않는다.

- 이용지침서 표지·관련 변수 표를 이미지로 확인하고, 위 표의 관련 페이지 텍스트를 읽었다.
- 지침서의 모든 변수에 대한 전처리 규칙이나 다년도 분석 설계는 아직 작성하지 않았다.
