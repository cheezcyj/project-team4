해당 자료에 공공누리 제4유형의 출처표시·상업적 이용금지·변경금지 조건이 안내되어 있어, 아래 이용 방식이 가능한지 사전에 확인하고자 합니다.

1. 원문을 개발용으로 저장하고 필요한 본문을 추출하여 개발자가 짧은 교육용 FAQ·요약문으로 재구성하는 방식
2. 사용자 질문과 관련된 요약문 일부를 자체 PC에서 실행하는 언어모델에 입력하여 답변을 생성하는 방식(RAG)
3. 생성된 답변과 원문 출처를 비영리 웹 시연 서비스에 표시하고, 필요한 경우 검토한 요약문을 보충 설명으로 직접 표시하는 방식
4. 프로젝트 코드와 함께 개발자가 작성한 FAQ·요약 JSON을 GitHub 등 공개 저장소에 공유하는 방식

현재 방식은 모델에 자료를 추가 학습시키는 방식이 아니라, 질문마다 필요한 요약문을 참고 입력으로 제공하는 방식입니다. 원문 PDF 전체와 그림·표를 서비스나 저장소에 재배포하는 방식은 요청 범위에 포함하지 않습니다. 개인의 진단이나 약물 용량 조정 대신 일반 교육정보를 제공하려는 목적입니다. 개발용 FAQ·요약문은 준비되어 있으며, 실제 적용 범위를 정하기 위해 문의드립니다.

위 항목 중 허용되는 범위와 별도의 서면 이용허락이 필요한 범위를 구분해서 안내해 주실 수 있을까요? 특히 변경금지 조건 아래에서 요약·재구성 및 AI 생성 답변이 가능한지, 허용될 경우 필요한 출처표시·수정 사실 표기·이용기간·재검토 조건도 알고 싶습니다. 건강정보 API 이용 신청과 별도로 허락받아야 하는 절차가 있는지도 안내 부탁드립니다.

필요하시다면 화면 예시, 데이터 처리 흐름, 작성한 요약문 샘플을 보내드리겠습니다. 다른 부서에서 담당하시면 담당 연락처 또는 전달 방법을 안내해 주시면 감사하겠습니다.
