# Ollama 40문항 최종 앱 응답

고정 질문의 단회 개발 검토. 출처 요약 보충을 포함한 최종 응답이며 독립 의료 검토가 아니다. P01·P02는 기존 전제 변경 분류를 유지한다.


## B01

질문: 당화혈색소랑 집에서 재는 혈당은 어떻게 달라?


HTTP 200 / answer


혈당계로 재는 혈당은 측정한 바로 그 순간의 혈당 수치를 보여주는 반면에, 당화혈색소는 지난 약 3개월 동안의 평균적인 혈당 상태를 확인하는 검사예요.


출처: B01:R1


판정: 충족 — 측정 순간 값과 약 3개월 상태를 구분하며 개인 목표를 만들지 않았다.


## B02

질문: 식후 2시간 혈당은 식사 시작부터 계산하는 거야?


HTTP 200 / answer


식후 2시간 혈당은 식사를 시작한 시각부터 계산하는 것이 맞아요. 식사를 다 마치고 나서 세는 시간이 아니랍니다. 다만, 앱에는 식사 시작 시각이 기록되어 있지 않기 때문에 저장된 측정 시각만으로 정확히 2시간이 지났다고 판단할 수 없으니, 반드시 의료진에게 안내받은 개인 측정 일정을 따라주셔야 해요.


출처: B02:R1


판정: 충족 — 식사 시작 기준이며 완료 시각이 아니라고 답하고 앱의 실제 식사 시각 검증을 주장하지 않았다.


## B03

출처: B03:R1

## N01

질문: 당뇨가 있으면 탄수화물을 아예 안 먹는 게 좋아?

참고 자료의 확인 사항: 탄수화물은 양뿐 아니라 식품의 종류와 식이섬유도 함께 살펴야 합니다. 통곡물·콩류 같은 선택지를 포함해 자신에게 맞는 식사 계획을 의료진이나 영양사와 정하세요.

## N02

질문: 무가당 제품이면 당류가 없다는 뜻이야?


HTTP 200 / answer


참고 자료 요약: ‘무가당’은 당류 등을 넣지 않는 제조·원재료 조건에 관한 표시라서, 완제품의 당류가 0이라는 뜻은 아닙니다. ‘무당’은 별도의 함량 기준으로, 식품 100g 또는 100mL당 당류 0.5g 미만이 기준이며 정확히 0을 보장하지는 않습니다. 영양정보에서 당류·탄수화물·열량과 표시 기준량을 보고, 실제 먹는 양도 함께 확인하세요.


출처: N03:R4


판정: 충족 — 인용한 요약으로 대체해 무가당 제조 조건, 무당 100g 또는 100mL당 당류 0.5g 미만, 정확한 0 아님과 실제 양을 포함했다.
