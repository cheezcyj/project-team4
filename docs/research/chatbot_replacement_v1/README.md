새 운동 카드는 **걷기·벽밀기·팔 들기**다. 기존 `chatbot_v5`의 걷기·고정식 자전거·탄력밴드 카드는 원본을 그대로 보존했다. 기존 평가본도 보존하고, 별도 대체 자료 평가본에서 자전거·밴드 질문의 기대 답변을 근거 부족으로 조정했다.

## 출처의 의미

`R1`·`R2`는 NIDDK 자체 교육 본문의 이용정책을 확인한 후보다. `R3`는 원문에 CC BY 4.0을 명시한 영양 권고문이다. `R4`는 국내 고시의 규범 본문으로, 저작권법 제7조제2호를 재사용 판단 근거로 기록했다. 식약처 뉴스레터는 최근 설명과의 대조에만 사용했으며 이미지나 대체 텍스트를 지식자료에 편입하지 않았다.

각 자료의 내용 근거와 프로젝트의 제품 규칙을 구분했다. 그림·표·로고·연결된 외부 문헌의 권리를 일괄 허락받았다고 처리하지 않는다. 허락이 필요한 기존 자료에서 문장을 가져와 새 출처만 붙인 문안도 아니다.

## 연결 상태와 다음 단계

1. 현재 앱은 이 폴더의 런타임 자료집을 검색한다. 웹문서의 절·고시 조항·저자·이용조건과 재구성 사실을 표시하며 이전 출처 ID를 모델 답변에서 허용하지 않는다.
2. 초안 예외는 기존의 demo 모드·명시적 미리보기 설정에만 적용한다. 기본/Supabase 경로의 게시·의료·이용조건 승인 확인은 유지한다.
3. 의학적 내용·한국어 표현·이용조건의 승인과 새 실제 모델 답변 평가는 별도다. 승인 일시나 재검토 기한을 임의로 채우지 않는다.

문의 초안과 이전 `chatbot_v5` FAQ·예시·지식자료는 보존했다. 개인 공복 기록 계산·동의 처리와 모델의 가중치·로드 설정은 이 자료 교체에서 수정하지 않았다.
