## 변경한 동작

앱은 이전 `chatbot_v5/knowledge.json` 대신 이 폴더의 `knowledge.json`을 검색한다. FAQ 13개가 다음 4개 출처에 연결된다. 원문 위치와 이용조건은 [SOURCES.json](SOURCES.json)에 기록했다.

실내 운동 예시는 벽밀기·팔 들기다. 자전거·탄력밴드 질문에 이 예시를 기구 사용법의 근거로 붙이지 않는다. 모델에는 선택된 요약·조건·절·출처 ID를 전달하며 이전 출처 ID를 반환하면 거부한다. 웹문서에 가상의 PDF 쪽수를 붙이지 않고 절·고시 조항, 저자·기관, 이용조건 링크, 한국어 요약·재구성 사실을 표시한다.

개인 기록 계산·동의 처리와 모델 가중치·로드 설정은 이번 교체에서 변경하지 않았다. 자료집의 승인 값은 모두 미승인으로 유지하며 기존 demo 모드의 명시적 초안 미리보기에서만 사용한다.

## 후속 실제 평가 — 2026-10-23

사용자가 로드한 Gemma 모델로 대체 40문항을 처음 실행했다. 자동 검사는 40/40, 최종 앱 응답의 내용 검토는 적용 가능한 38개 중 36개 충족·2개 미충족이었다. 실행 전에 범위 변경을 확인한 P01·P02는 별도 표시했다. 출처가 포함된 생성 답변은 16개이며 N03 1개에는 서버의 기존 출처 요약 보충이 적용됐다.

B03은 메모만으로 혈당 변화 원인을 증명할 수 없다는 한계가, N02는 무당의 함량 기준과 무가당의 제조 조건 구분이 빠졌다. 앱·자료집·고정 문항은 변경하지 않았다. [평가 보고서와 원본 응답](../assistant-eval-replacement40/REPORT.md)에 판정 근거·실행 설정·해시·후속 항목을 남겼다. 이전 표의 실제 평가 미실행은 2026-10-22 연결 검증 당시의 상태다.

## 누락 보완 후 재평가 — 2026-10-23

자료집 `replacement-v1-draft-3`은 B03의 원인 증명 한계, N03의 무당·무가당 구분 및 정확한 0 보장 불가, X04의 기존 운동 제한을 요약에 유지한다. 필수 조건 누락 검사에는 탄수화물의 식이섬유·섭취량과 새 활동 전 확인사항도 포함한다. B03·N03의 필수 설명이 불완전하면 실제 인용한 요약으로 대체한다. 자료 승인 값과 출처 원문은 변경하지 않았다.

같은 모델·생성 설정·40문항으로 재평가한 최종 결과는 자동 40/40·적용 가능한 내용 38/38이다. 전제가 바뀐 P01·P02 2개는 별도이며 N05·X02 2개는 요약 대체·보충을 포함한 최종 앱 응답이다. 중간 결과를 덮어쓰지 않았고, [보완 보고서](../assistant-eval-replacement40/HARDENING_REPORT.md)에 전체 비교·답변·한계를 남겼다.
