# 도우미 40문항 최초 평가

후속 보완 결과는 [미충족 항목 보완과 재평가](HARDENING_REPORT.md)에 있다. 아래 최초 기준선과 응답 원문은 그대로 보존한다.

2026-10-22 로컬 앱과 실행 중인 Gemma 4 E4B로 40개 시나리오를 평가했다. **자동 검사는 35/40, 응답 원문 검토까지 포함한 기대 결과 충족은 32/40(80%)**였다. 앱과 지식 자료는 평가 전후 동일하며 이번 작업에서 답변 동작을 수정하지 않았다.

이 점수는 작성한 제품 기준의 충족률이다. 의학적 정확도나 실제 서비스 승인 점수가 아니다. 응급 도움 안내와 치료 변경 요청 처리에 미충족 항목이 있어, 개인 기록 연결보다 해당 경계를 먼저 보완하는 것이 좋다.

## 확인한 범위와 한계

- 실행 전 [40문항과 기대 결과](QUESTIONS.md)를 고정했다. 질문 해시는 `1c4e6501a7af7de2840dbb2e0504563d34221f7b3f5fe8cdfb759023e5c982f0`이다. 결과를 보고 기대 결과를 낮추거나 앱을 바꾸지 않았다.
- 자동 검사는 HTTP 상태·오류 코드·응답 구조·예상 분류·자료에 있는 출처와 필수 지식 ID를 확인한다. 내용 검토는 고정한 `must`·`must_not`을 40개 응답 원문에 대조한 Codex의 단회 검토다. 별도 판정 모델이나 의료 전문가 검토를 사용하지 않았다.
- 이전 문체 비교의 질문 8개를 포함했고 P05는 기존 오류 질문의 변형이다. 새로 작성한 문항도 현재 지식·코드 범위를 보고 만든 것이므로 독립적인 외부 검증 세트가 아니다.
- P07은 동의 철회를 **말로 요청한 경우**다. 실제 동의 철회 API·진행 중 생성 취소·DB 접근 차단을 검증한 것은 아니다. 현재 도우미에는 개인 기록 도구가 없다. 결측값 처리·기간 비교 계산·DB 격리·혈당 CSV 시험 12묶음도 이 평가 범위에 포함하지 않았다.
- A03은 다른 계정 ID·대화 이력·모델 주소를 함께 넣은 요청 한 건이다. A05는 명령 삽입 한 건에서 공격을 수행하지 않는지 확인했다. 모든 변형의 접근 공격에 안전하다는 뜻은 아니다.
- 자료 승인·의료 검토·이용조건 승인 상태는 변경하지 않았다. 초안 자료를 허용한 로컬 가상 계정만 사용했다.
