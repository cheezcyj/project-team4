# 고정 도움 안내의 근거와 구현 범위

확인일: 2026-10-22. 의료 검토·서비스 배포 승인을 받은 상태는 아니다.

이 파일은 모델이 생성하는 지식 답변과 별도로, 서버의 제한된 표현 규칙이 반환하는 도움 경로를 설명한다. 특정 질환을 확정하거나 응급 처치·약물 용량을 안내하는 자료가 아니다.

| 자료 | 확인 내용 | 구현에 사용한 범위 |
| --- | --- | --- |
| 질병관리청 국가건강정보포털 [심폐소생술](https://health.kdca.go.kr/healthinfo/biz/health/gnrlzHealthInfo/gnrlzHealthInfo/gnrlzHealthInfoView.do?cntnts_sn=6226) | 반응·호흡 확인과 119 도움 요청을 설명한다. | 현재 의식 소실·반응 없음 표현에서 일반 지식 생성보다 도움 요청을 앞세운다. 심폐소생술 절차·수치·진단은 챗봇 문안에 가져오지 않는다. |
| 질병관리청 [심근경색 조기증상 의심되면 즉시 119!](https://www.kdca.go.kr/bbs/kdca/47/218749/artclView.do) | 갑작스러운 가슴통증·호흡곤란 등 조기증상이 의심될 때 즉시 119 도움을 요청하도록 안내한다. 게시·최종수정 2025-12-16. | 현재 호흡 곤란·가슴 압박 등으로 감지한 표현에는 첫 문장에서 119 도움 요청을 안내한다. 해당 질환이라고 판정하지 않는다. |

위 자료는 근거를 확인한 링크다. 원문·그림·영상은 복사하지 않았고 모델 검색 자료집에 추가하지 않았다. 두 번째 자료의 페이지에는 출처표시·비상업적 이용·변경금지 조건이 표시되어 있어, 의료 검토와 이용조건 검토 없이 원문이나 영상을 서비스 콘텐츠로 재배포하는 허가로 해석하지 않는다.

서버 문안은 “지금 바로 119에 연락해 도움을 요청하세요.”로 시작해 채팅 답변을 기다리지 않고 상담원의 안내를 따르도록 한다. 이 문안의 사용 조건을 정하는 정규식은 개발자가 작성한 제품 규칙이며, 공식 기관이 승인한 분류 기준이 아니다.

현재 규칙은 일부 한국어 의식·호흡·가슴 증상 표현만 다룬다. 부정문·가정·용어 질문·해소된 과거 증상을 구분하는 회귀 검사를 추가했지만, 혼합 문장·인용·오탈자·음성 전사·기타 언어·다른 응급 상황까지 판별한다고 보장하지 않는다. 일반 지식 자료나 모델의 답변만으로 개인의 안전 여부를 확정하지 않는다.

약물 중단·용량 조정·개인 진단은 기존 제품 정책대로 답하지 않는다. 숫자와 일부 한글 수치 표현을 구분하되 검사값을 새 단위로 환산하거나 치료 기준과 비교하지 않는다. 응급 의심 표현이 함께 있으면 일반적인 수치·약물 안내보다 도움 요청을 우선한다.
