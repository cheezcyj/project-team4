# Ollama 기본 서버 연결 평가

2026-10-23 한국시간 15:38:35~15:38:52, 실제 Supabase Auth·DB와 Ollama 기본 서버를 연결해 **응답 형태·출처 검사 8/8, 시나리오 묶음 5/5**를 통과했다. 모델 질문 요청은 **4회, HTTP 200 4회, 재시도 0회**다. 별도 답변 원문 검토에서는 G03의 세부 함량 기준 누락을 확인했다. 연결 성공과 내용의 완전성을 구분한다.

후속 보완에서 해당 누락 검사를 강화하고 40문항·실제 Supabase·팀 시연을 재확인했다. 아래 최초 실행 결과와 원본은 유지하며, 해결 여부는 [최종 보완 보고서](../assistant-eval-replacement40/OLLAMA_REPORT.md)를 참고한다.

[실행 원본·전체 응답·검토](runs/20261023-ollama/)와 [재실행 안내](../../ASSISTANT_OLLAMA.md)를 함께 참고한다. 이전 [LM Studio 평가](REPORT.md)와 [서버 비교](../assistant-runtime-comparison/REPORT.md)는 보존했다. 마지막 비교 확인의 11480·1234 연결 거부는 사용자가 직접 종료했다고 후속 확인했으므로 엔진 장애로 집계하지 않는다.

사용자 Ollama 앱과 서버는 재시작하지 않았으며 Windows 사용자 환경변수를 변경하지 않았다. 4슬롯 설정을 위한 프로세스 종료·환경변수 변경 명령은 실행 전 자동 승인 검토에서 ‘정책에 의해 차단’으로 거절되었다. 현재 11434의 실제 설정은 1슬롯이며 이전 격리 11435의 4슬롯 결과와 혼합하지 않는다.

모델 등록 후 빈 프롬프트 사전 로드 1회를 실행했다. 빈 응답과 `done_reason=load`를 확인했고 질문 생성 4회에 합산하지 않았다. 현재 정상 응답은 각각 앱 기준 690/461/627/356ms였다. G01에는 브라우저 조작 시간이 포함된다. 단일 가상 계정·로드된 모델·짧은 질문 4개의 관찰이며 cold start·토큰 속도·동시 처리 성능을 뜻하지 않는다.

네 일반 응답 모두 기존 요약 보충 없이 모델 문장을 반환했다. G03은 `answer-conditions.ts`의 현재 검사에서 ‘함량 기준’이라는 표현만으로 통과한다. 이 때문에 `sourceSupplemented=false`여도 원문 요약의 수치·기준 단위가 모두 남았다고 판단할 수 없다. 기존 LM Studio 결과 검토에서 확인했던 수치 기준이 이번에는 최종 응답에 누락됐으므로 **이 항목의 내용 검토를 완전 통과로 기록하지 않는다**. 후속 보완 대상으로 남겼으며 이번 모델 서버 교체에서 검색·프롬프트·보충 규칙·지식 원본을 함께 변경하지 않았다.

이 검토는 현재 프로젝트 자료와 고정 질문에 대한 대조다. 독립 의료 검토·새 표현의 품질·40문항 전체 재평가를 뜻하지 않는다.

## Auth·DB와 화면

- 기본 Supabase 앱은 일반 초안 답변을 차단한다. 임시 앱은 가상 계정 A만 허용하며, 비허용 계정·비로그인·AI 처리 미동의·다른 Origin·본문 권한 위조를 거절했다.
- A의 공복 기록 110·130은 2건·평균 120·최소 110·최대 130으로 요약됐다. B의 250은 제외됐고 A에서 해당 기록 직접 조회는 404였다.
- 다른 탭에서 130→140 수정 후 기존 도우미 화면이 닫히고 새 평균은 125였다. 기록 요약은 모델을 호출하지 않았다.
- G01과 요약은 360px 실제 브라우저에서 표시를 확인했다. 모델 경계에서는 질문·공개 지식만 확인됐고 가상 계정 ID·이메일·시험 기록 ID·메모는 전달되지 않았다.
- 시험 기록 3개를 HTTP 200으로 삭제했다. 임시 3006·11481은 종료했고 기본 11434·3005는 유지했다. 계정과 기존 데이터는 보존했다.

## 변경과 검증

로컬 `.env.local`은 모델 URL·모델 이름 두 항목만 변경했다. Supabase 연결 설정, 초안 미리보기 0, 빈 평가 허용 목록을 유지했다. 앱 어댑터 수정 없이 호환 API를 사용한다. 평가 러너에는 `--provider ollama`를 추가해 `/api/ps`와 `/api/version`으로 이미 로드된 모델을 확인한다. LM Studio 기본 옵션은 유지했다.

lint, 러너 문법 검사, 인자 없는 dry run, 위 실제 Auth·DB·모델 평가를 확인했다. 앱 런타임 코드는 변경하지 않았고 전체 빌드·단위 테스트·40문항은 이번에 다시 실행하지 않았다. Next가 생성한 평가용 타입 경로와 AGENTS 파일은 원본을 로컬에 보관한 뒤 작업 전 상태로 복구했다. README·마이그레이션·기존 미커밋 작업은 보존했으며 커밋·PR은 하지 않았다.

공유 캡처에는 비밀 환경 파일·가상 계정 비밀번호·쿠키·인증 헤더·전체 서버 로그를 넣지 않는다. 원본은 `.local/assistant-ollama-switch-20261023/`에 보관하고, 공유본은 선택한 JSON·요청/응답·화면·검증 로그·소스 사본과 SHA-256 목록을 고정한다. 화면의 계정 표시는 시험용 가상 계정이다.
